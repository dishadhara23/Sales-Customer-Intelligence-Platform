**Start here → [`../../docs/TABLEAU_SETUP.md`](../../docs/TABLEAU_SETUP.md)**

That guide takes you from "nothing installed" to a published Tableau Public
link, click by click, in about 90 minutes.

## What's in this folder

| | |
|---|---|
| `extracts/*.csv` | **Verified.** Pre-aggregated data, ~250 KB total, regenerated by `python -m src.etl.run_pipeline`. Committed so the workbook is usable straight after a clone. |
| `sales_intelligence.twb` | **Not verified.** Generated XML, well-formed, but never opened in Tableau Desktop — it was not available on the machine that built this. Build from the guide instead; it takes about as long and you'll actually know the tool. |

All aggregation happens in SQL, so Tableau does presentation only. That keeps
the business definitions in version control and under test, and means the
Tableau dashboard, the HTML dashboard and the notebook cannot disagree.
